# Ethics, data handling and sign-off

**Nothing in this folder has been approved.** These are drafts prepared so that the coordinator
can put them in front of the supervisor and, where required, the department or the university. Every
approval, signature and date in them is a placeholder marked `PENDING`. Whether the university
requires an ethics review for this project, and in what form, is the university's decision; the
statement below is the researcher's description of the project, not a ruling.

| File | Purpose | Status |
|---|---|---|
| `data_management_plan.md` | What data the project creates or uses, where it lives, who can see it, what is published, what is deleted | drafted; PENDING supervisor review |
| `ethics_statement_draft.md` | A description of the people involved and the risks, for the supervisor and the ethics contact | drafted; PENDING |
| `supervisor_signoff.md` | The decisions and documents that need the supervisor's written approval before the main run | PENDING (unsigned) |
| `independent_analyst_consent_template.md` | Consent and information text for the optional timed-analyst subset | TEMPLATE; must not be used until the department allows the subset |

What the project does not need, by design (blueprint §33): recruited participants in the core
design, personal data, production credentials, or real malware. If any of these changes, stop and
update these documents first.
